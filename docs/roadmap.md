## 済：プロトタイプ（〜2026-09-27）

- 髪型カタログ（10髪型）、絞り込み、詳細、カード作成、共有リンク、印刷、お店さがしのリンク、端末内の集計を作った。
- 見本イラストは、全10髪型の正面・横・後ろと、刈り上げ比較（後ろ・横の4段階）ができた。
- 参考写真の収集ルール、イラスト制作の指示書、Codex向けの作業指示を整えた。
- 海外のデザイン参考を集めた（[design-references.md](design-references.md)）。

## v1-a：データの土台をそろえる（実装は小さめ）

目的：将来の相談ツールに向けて、データを作り直さずに済む形にしておく。

1. 調整軸の一覧（`HM_AXES`）を作り、絞り込み・カード作成・比較画像がそこを参照するようにする。
2. 相談メモのデータの形（`wish` / `proposals` / `agreed`、`schemaVersion`）に移す。古いカードと共有リンクは読めるようにしておく。
3. 行動の記録に「比較を見た」「見せた」「合意」を足す。
4. 髪型に「再現しやすさ」「手入れ」を足す（まず内容を決める）。

## v1-b：比べて選べるようにする

目的：「違いが分かって選べる」を、イラストで支える。

1. 比較画像を追加する（Codex）：前髪（下ろす／上げる）、耳まわり（残す／短く）、刈り上げの短さ。
2. 髪型の詳細に「違いを比べる」を足す。
3. 「希望を選ぶ」を1軸ずつの画面にし、「わからない・おまかせ」を足す。
4. デザインの作り直し（[design-references.md](design-references.md) の方向性をもとに）。

## v1-c：来店時の相談

目的：親子と美容師さんが、同じ画面で決められるようにする。

1. 相談メモの「見せる」表示を、搭乗券のように整理する（大事な項目を大きく、詳しい内容は2ページ目）。
2. 「相談する」モードを作る。比較画像を切り替えられ、美容師さんの理由つきの提案と合意を記録できる（アカウントなし、親子の端末に保存）。
3. 合意後の相談メモ（希望・提案・合意）を、共有リンクで美容師さんに渡せるようにする。
4. 前回の合意をもとに、次の相談メモを作れるようにする。

## v1-d：女の子の髪型

目的：対象を小学生の親子全体に広げる（[spec.md](spec.md) 9章）。

1. ~~女の子の髪型の種類を決める~~（8種類。済）
2. ~~長い髪型用の調整軸を足し、髪型ごとに使う軸を決める~~（済。毛量の軸は作らない）
3. ~~参考写真を集める~~（済）。女の子のモデルの見本イラストを作る（Codex、[codex-girls-task.md](codex-girls-task.md)）。
4. ~~一覧を、性別ではなく長さと特徴で探せる構成にする~~（済）
5. 見本イラストができたら、編集部のおすすめに女の子の髪型を加える。女の子用の比較画像（長さの位置など）を検討する。
