# Codex作業指示：スポーツ刈り・マッシュの作り直し（似た髪型と見分けられるように）

全10髪型を並べて確認したところ、2組がほぼ同じ絵になっていた（2026-09-27）。

| 作り直す髪型 | 似てしまった髪型（こちらは変えない） | 何が似ているか |
|---|---|---|
| `sports` さっぱりスポーツ刈り | `twoblock` キッズツーブロック | 正面・横・後ろすべて。こめかみまでの刈り上げに上の髪がかぶさる段があり、後ろがV字 |
| `mash` マッシュ | `sidepart` 横流しショート | 正面で前髪を斜めに流しているところ。横・後ろも近い |

`twoblock` と `sidepart` は今の絵をそのまま使い、それぞれの組の**基準**にする。`sports` と `mash` だけを作り直し、基準と並べてはっきり見分けられるようにする。

## 1. 最初に読むもの

| ファイル | 内容 |
|---|---|
| [illustration-guide.md](illustration-guide.md) | 画風、描写ルール、避ける表現。**必ず守る** |
| [codex-image-task.md](codex-image-task.md) | 髪型見本の作り方（3方向を横一列の1枚に並べる、分割、チェック） |
| `img/styles/natural-sheet.webp` | 画風と顔立ちの基準 |

Web上の写真や `docs/references.csv` のURL先の画像は、生成ツールへ入力・参照させない。参照画像として使ってよいのは、このリポジトリの `img/` にある自作の画像だけ。

## 2. 作り方を変える点

これまでの作り直しでは、「ツーブロックにしない」と書いても、短い髪型が「毛束の多いショート＋刈り上げ」の同じ型に寄ってしまった。そこで今回は、**狙った形に近い自作の画像を参照画像にして、そこから寄せる**。

| 作り直す髪型 | 参照画像 | 寄せ方 |
|---|---|---|
| `sports` | `img/styles/buzz-sheet.png`（ボウズ風） | ボウズの短さ・なじんだ刈り上げ・丸い形を土台に、**上だけ少し長く**する |
| `mash` | `img/styles/longmash-sheet.png`（長めマッシュ） | 長めマッシュの丸いきのこ形・そろった前髪を土台に、**全体を短く**する |

どちらも、画風と顔立ちは `natural-sheet.webp` に合わせる。

## 3. 指示文

下の指示文をそのまま使う。参照画像は2章のとおりに添える。

### `sports` さっぱりスポーツ刈り

```text
【この髪型の見分けどころ】参照画像のボウズ（全体が1cm前後の坊主）を土台にして、頭の上の部分だけを3〜4cmに伸ばした、短くて丸いスポーツ刈り。上の髪は短いので、横や後ろの刈り上げの上にかぶさらない。上の髪と刈り上げの境目に段差やひさしを作らず、下から上へ長さがなめらかにつながる。横から見ると、頭の形に沿った丸いシルエットで、後ろ姿にV字の段はない。前髪は短く、まゆの2〜3cm上で、おでこがはっきり見える。毛先は軽く不ぞろいだが、束を立てない。サイドはこめかみ〜はちの下まで、後ろは低めにバリカンで短くし、上の髪となじませる。地肌が白く見えるほど短くしない。
10歳くらいの日本の男の子の髪型見本を作成する。目的は美容室で髪型を選び、美容師に希望を伝えること。線画を主体とした、落ち着いたマンガ風のイラスト。写真風ではなく、髪型の輪郭、毛束、前髪、トップ、耳まわり、後頭部、襟足が読み取れる描写にする。髪型を主役にし、顔は控えめにする（目は小さめで、瞳の光は控えめ）。
同じ子ども、同じ髪型を、正面・真横（左向き）・後ろの3方向から描き、左から正面・横・後ろの順に横一列に並べた1枚の横長の画像にする。3つの絵は同じ縮尺・同じ高さにそろえ、絵と絵のあいだは十分にあける（重ねない）。各方向で頭の大きさ、髪の長さ、毛流れ、刈り上げの範囲、襟足の形を一致させる。
耳まわり：出す（耳全体が見える）。襟足：すっきり短く。
描く範囲は頭から首まで（肩の線まで）。服は描かない。髪色は黒または暗い茶色で、黒の線と控えめなハッチングで表す。背景は白の無地（透明にしない）。背景の模様、小物、文字、ラベル、ロゴは入れない。頭頂部のはねた毛（アホ毛）や飾りの毛は入れない。カラー、パーマ、剃り込み、ラインは加えない。
```

### `mash` マッシュ

```text
【この髪型の見分けどころ】参照画像の長めマッシュを土台にして、全体を短くしたマッシュ。前髪は、まゆ毛くらいの長さで、毛先を横一直線に厚めにそろえる（斜めに流さない、分け目を作らない）。正面から見て、前髪の下端が水平な一本の線になり、前髪からサイドまで丸くつながる、きのこのような丸いシルエット。サイドの髪は耳の上半分にかぶさり、耳の下半分だけが見える。横から見ても丸い形で、刈り上げは見えない（襟足の生えぎわだけ短く整え、上の髪がかぶさって見えない）。後ろ姿は丸く、襟足は自然に残す。重すぎるおかっぱにはせず、表面に軽い毛束を少し見せる。

同じ子ども、同じ髪型を、正面・真横（左向き）・後ろの3方向から描き、左から正面・横・後ろの順に横一列に並べた1枚の横長の画像にする。3つの絵は同じ縮尺・同じ高さにそろえ、絵と絵のあいだは十分にあける（重ねない）。各方向で頭の大きさ、髪の長さ、毛流れ、前髪の線、襟足の形を一致させる。
描く範囲は頭から首まで（肩の線まで）。服は描かない。髪色は黒または暗い茶色で、黒の線と控えめなハッチングで表す。背景は白の無地（透明にしない）。背景の模様、小物、文字、ラベル、ロゴは入れない。頭頂部のはねた毛（アホ毛）や飾りの毛は入れない。カラー、パーマ、剃り込み、ラインは加えない。
```

## 4. 手順（1髪型ごと）

1. 今の画像を `img/styles/drafts/` に移す（上書きしないため）。
   - `sports-sheet.png`・`-front`・`-side`・`-back` → `img/styles/drafts/sports-*-r3.png`
   - `mash-sheet.png`・`-front`・`-side`・`-back` → `img/styles/drafts/mash-*-r1.png`
2. 3章の指示文と2章の参照画像で生成し、`img/styles/<ID>-sheet.png` に保存して3枚に分ける。

   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts/split-sheet.ps1 -src img/styles/sports-sheet.png -outDir img/styles -prefix sports
   ```

3. **似た髪型と並べた画像**を作って確かめる（5章）。

   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts/montage-styles.ps1 -view front -ids "sports,twoblock,buzz" -out check-sports-front.png
   powershell -ExecutionPolicy Bypass -File scripts/montage-styles.ps1 -view side -ids "sports,twoblock,buzz" -out check-sports-side.png
   powershell -ExecutionPolicy Bypass -File scripts/montage-styles.ps1 -view back -ids "sports,twoblock,buzz" -out check-sports-back.png
   ```

   `mash` は `-ids "mash,sidepart,natural,longmash"` で同じように3方向を作る。確認用の画像はリポジトリの外（作業用フォルダ）に置き、コミットしない。
4. 5章を満たさなければ、違う点を指示文の【見分けどころ】に書き足して生成し直す（1髪型につき最大3回）。不採用版は `img/styles/drafts/` に移す。
5. `js/data.js` は変えない。ファイル名が同じなので、画像を置きかえればアプリに反映される。
6. `node serve.js` でアプリを起動し、http://localhost:5173/#/style/sports と #/style/mash で3方向が表示されることを確かめる。

3回とも合格しなかった場合は、いちばん良かった案を `img/styles/<ID>-*.png` に置き、報告に「最良案」と書く。

## 5. チェック項目

[codex-image-task.md](codex-image-task.md) の4章に加えて、**並べた画像で**次を確かめる。1枚だけを見て合格にしない。

### `sports`

- [ ] `twoblock` と並べて、正面・横・後ろのどれでも、ひと目で別の髪型だと分かる
- [ ] 横と後ろで、上の髪が刈り上げにかぶさる段（ひさし）がない。後ろ姿にV字の段がない
- [ ] トップが `twoblock` より明らかに短く、`buzz` より少し長い（3つの中で真ん中の長さ）
- [ ] 前髪がまゆの2〜3cm上で、おでこがはっきり見える
- [ ] 地肌が白く見えるほど短くない

### `mash`

- [ ] `sidepart` と並べて、正面でひと目で別の髪型だと分かる（前髪が斜めに流れていない）
- [ ] 前髪の下端が水平な一本の線で、厚めにそろっている
- [ ] 前髪からサイドまで丸くつながる、きのこのような形
- [ ] 耳の上半分に髪がかぶさっている
- [ ] 横と後ろで刈り上げが見えない
- [ ] `longmash` より全体が短い（耳が完全にはかくれない、襟足が短い）

## 6. 変えてはいけないもの

- `sports` と `mash` 以外の髪型の画像（とくに基準にする `twoblock`・`sidepart`）は触らない。
- `js/data.js`・`js/app.js` などのコードは変えない。
- git のコミットやpushはしない（レビューのあとで反映する）。
