# ヘアみっけ｜髪型イラスト制作指示書（案）

## 1. イラストの目的

髪型をかっこよく見せるだけでなく、親子が「この形がいい」と選び、美容師さんに希望を伝えるための見本として描く。見る人が次の特徴を見分けられることを優先し、かっこよさや絵としての華やかさはその次に考える。

- 前髪の長さ、形、分け方
- 頭頂部の長さとボリューム
- サイドの長さ、耳の見え方
- 刈り上げの有無、短さ、高さ
- 後頭部の丸みと襟足の形
- 髪全体のシルエット

## 2. 参考写真の使い方

髪型は、Web上の既存のヘアスタイル写真を参考にして作る。写真は**髪型の特徴を知るための資料**として使い、写真そのものや写っている人物は作品に持ち込まない。

### 2-1. 集める

- 1つの髪型につき、**別々の出典から2〜3件**を集める。1枚の写真に似すぎないよう、複数の写真に共通する特徴を髪型として採用する。
- 正面・横・後ろのうち、写真で確認できた方向を記録する。サロン写真は正面や斜めが多く、後ろや真横がないことがある。足りない方向は別の写真で補い、補ったことを記録する。
- 利用規約で画像の転載、AIでの利用、機械的な収集を禁じているサイトは使わない。
- 集めた情報は [references-template.csv](references-template.csv) の形式で記録する。

### 2-2. 保管する

- 写真ファイルは、関係者だけが見られる作業用フォルダに置く。**このリポジトリやアプリには写真を入れない。** リポジトリに残すのは出典URLと特徴メモだけにする。
- 子どもが写っている写真では、名前、学校、顔の特徴など、人物を特定できる情報を記録しない。

### 2-3. 特徴を文章にする

写真から、アプリの絞り込み項目と同じ観点で特徴を書き出す。この文章をイラスト制作と画像生成の指示に使う。

| 観点 | 書き方の例 |
|---|---|
| 全体の長さ・トップ | 短め／ふつう／長め、トップの丸み・高さ |
| 前髪 | ほぼなし／短め／まゆ毛くらい／まゆ下、形（自然におろす・そろえる・横に流す・分ける・上げる） |
| 耳まわり | 出す／半分かかる／かくす |
| 刈り上げ | なし／低め／中くらい／高め、境界（なじませる・はっきり） |
| 襟足 | 短め（すっきり）／ふつう（自然に残す）／長め |
| 毛流れ・質感 | 直毛、毛先の軽さ、分け目の位置 |

### 2-4. 描く・生成する

- イラストレーターが描く場合は、写真をなぞったり、写真の上から描いたりしない。
- 画像生成を使う場合は、**参考写真を生成ツールへ直接入力しない**（画像から画像への変換や参照画像として使わない）。2-3で書いた特徴の文章と、共通のモデル設定だけで生成する。
- 写真の人物、服装、ポーズ、構図、背景は再現しない。

### 2-5. 確認する

- 完成したイラストを参考写真と並べ、人物・服装・ポーズ・構図が似ていないかを確認する。
- 写真にない特徴（カラー、剃り込み、パーマなど）を足していないかを確認する。

> 注：個人プロジェクトのため、法務の確認は行わない（2026-09-27決定）。上の運用ルール（特徴メモとしてだけ使う、写真を保存・転用しない、生成ツールに入力しない）は続ける。商用化する場合は改めて判断する。

## 3. 基本の画風

- 線画を主体にした、マンガ・イラスト風
- 写真のような質感ではなく、髪の輪郭や毛束が読み取れる描き方
- 黒または濃いグレーの線を基本にし、線の太さに少し変化をつけて、頭の輪郭と髪の外形を分かりやすくする
- 毛束の流れが分かる線を入れる。ただし、一本ずつ描き込みすぎない
- 影は少なめにし、必要な部分だけ薄いグレーや控えめなハッチングで表す
- 強い光沢、立体的なツヤ、派手なグラデーションは避ける
- 清潔感があり、落ち着いた髪型カタログの雰囲気にする
- 特定の作品・キャラクターの線や顔つきは再現せず、一般的なマンガ風の表現にする

## 4. モデルとなる子ども

- 日本の小学生男児。小学校中学年から高学年くらい
- 1つの髪型の正面・横・後ろでは、同じ子どもに見えるようにする
- 顔立ちは自然で控えめにし、表情は無表情か穏やかな表情にする
- 大人びた顔、強いメイク、アクセサリー、極端な表情は描かない
- 描く範囲は頭から首まで（肩の線まで）とし、服は描かない（ナチュラルショートの見本に合わせて統一）
- 目は小さめにし、瞳の光は控えめにする
- 顔を似せることより、髪型の比較しやすさを優先する

## 5. 描く方向

1つの髪型につき、同じ子どもの次の3方向を描く。並びは左から正面・横・後ろの順に統一する。画像生成では、3方向を横一列に並べた1枚の横長画像として作り、`scripts/split-sheet.ps1` で3枚に分ける。

1. 正面：前髪、分け目、トップのボリュームを見る
2. 横：耳まわり、サイド、刈り上げの高さ、後頭部へのつながりを見る
3. 後ろ：後頭部の形、襟足、刈り上げの範囲を見る

- 正面は顔を正面に向ける
- 横は真横に近いプロフィールにし、斜め向きにしすぎない（左向きに統一）
- 後ろは頭の中心を正面に向け、左右の形を比較できるようにする
- 3方向とも、頭の大きさ、髪の長さ、毛流れ、刈り上げ範囲を一致させる
- 3方向のイラストは、同じ高さ・同じ縮尺で揃える

## 6. 髪型の描写ルール

### 髪の外形

- 髪型を見分ける最も大切な情報として、外形を明確にする
- 頭の輪郭に髪がどう乗っているかが分かるように描く
- 前髪、サイド、トップ、後頭部、襟足を一体の髪型として整合させる
- 実際の小学生が美容室で注文できそうな、現実的な形にする
- 不自然に尖らせたり、頭から大きく浮いたりする髪は避ける

### 毛束・毛流れ

- 毛束の方向は、実際に髪が流れる方向に沿わせる
- 毛束は形を説明するために描き、装飾として増やしすぎない
- 束の太さや本数を揃えすぎず、自然なまとまりを残す
- 前髪が目にかかるか、眉の上にあるかなど、長さを判断できるように描く
- クセ毛やパーマ風の髪型は、直毛の髪型と区別できる程度に描く

### 刈り上げ・短い部分

- 刈り上げがある場合は、頭皮に近い短い部分と長い髪の境界を明確に描く
- 刈り上げの高さは、横と後ろで確認できるようにする
- 境界がなじむ髪型は、線で強く区切らず、長さの変化を段階的に描く
- 刈り上げがない髪型に、短い部分を描き足さない
- バリカンのミリ数はイラストだけで断定せず、短さの目安と美容師さんへの相談の余地を残す
- 髪型に含まれない剃り模様やラインを加えない

## 7. 色と背景

- 髪色は黒〜暗めの茶色。髪色や光の当て方は、全髪型で揃える
- 肌、服、背景には強い色を使わない
- 背景は白または薄いニュートラルカラー。模様、風景、小物、文字、ロゴは入れない
- 影色は薄いグレーなどに抑え、髪の境界を隠さない

## 8. 避ける表現

- 髪型が分からなくなるほどのデフォルメ
- 顔や目を大きく描き、髪より顔が目立つ表現
- 極端な逆立ち髪や、実際には再現しにくい髪型
- 頭頂部のはねた毛（アホ毛）などの飾りの毛
- 角度ごとに髪の長さ、分け目、刈り上げの範囲が変わること
- 髪型に含まれないカラー、剃り込み、パーマなどの追加
- 強いツヤ、細かすぎる一本線、複雑な背景
- 参考写真の人物、服装、ポーズ、構図をそのまま写すこと

## 9. アプリでの見せ方

- 一覧カードでは、違いが一目で分かる正面イラストを使う
- 詳細画面では「正面・横・後ろ」を切り替えて表示する
- 刈り上げの比較は、同じ子・同じ角度・同じ髪色で、刈り上げだけを変えた共通の比較画像を使う（なし／低め／中くらい／高め × 横・後ろ）
- 画像内に説明文を描き込まず、ラベルや説明はアプリの文字として表示する

### 画像ファイルの置き方

| 種類 | 置き場所 | 登録先 |
|---|---|---|
| 3方向を並べた元画像 | `img/styles/<髪型ID>-sheet.png`（または .webp） | —（残しておく） |
| 髪型の見本 | `img/styles/<髪型ID>-front.png`・`-side.png`・`-back.png` | `js/data.js` の `HM_IMAGES` |
| 刈り上げ比較 | `img/fade/back-0.webp`〜`back-3.webp`、`side-0`〜`side-3` | `js/data.js` の `HM_FADE_IMAGES` |

- 形式はPNG（またはWebP）。縦横比は 10:11 にそろえる（分割スクリプトが自動でそろえる）。
- 画像を登録していない髪型は、アプリ内の簡易図で代わりに表示する。

## 10. できあがりの確認

- 正面・横・後ろで同じ髪型に見えるか
- 横と後ろから見て、刈り上げや襟足の形が判断できるか
- 似た髪型同士を並べた時、違いが見えるか
- 美容師さんに現実的に頼めそうか
- 画像の主役が顔ではなく髪型になっているか
- 不要なカラーや剃り模様などが追加されていないか
- 一覧カードの小さな表示でも、髪の輪郭がつぶれていないか
- 参考写真の人物・構図に似すぎていないか（2-5）

## 11. 進め方

1. 基準の1枚として **ナチュラルショート** を作った（`img/styles/natural-sheet.webp`）。以降の画風の基準にする。
2. 次に **キッズツーブロック** で、刈り上げの境界が横と後ろで一致するかを確認する。
3. 問題がなければ、ほかの髪型と刈り上げ比較画像に広げる。

Codexに生成させるときの作業指示は [codex-image-task.md](codex-image-task.md) にある。

髪型ごとの生成用の指示文は [illustration-prompts.md](illustration-prompts.md) にある（`node scripts/build-prompts.js` で `js/data.js` から作り直せる）。
