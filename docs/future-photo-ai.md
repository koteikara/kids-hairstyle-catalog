# 写真の取り込み・AI試着の検討事項（将来機能）

- 作成：2026-09-27
- 位置づけ：将来機能の検討メモ。**初期版では実装しない。** 初期版は子どもの写真を扱わず、利用者にAIサービスの契約や設定を求めない（[spec.md](spec.md) 7章）。

## なぜ別に検討するか

「自分の写真で髪型を試す」機能は、子どもの顔写真という、特に慎重に扱うべき情報を使う。加えて、画像生成の品質と費用も大きく変わる。カタログや相談メモとは切り離し、次の論点に答えが出てから判断する。

## 論点

| 論点 | 確かめること |
|---|---|
| 写真の保存 | 端末の中だけで処理できるか。サーバーに送る場合、どこに・どれだけの期間置くか |
| 処理後の削除 | 生成が終わったら元の写真と結果をすぐ消せるか。消したことを利用者に示せるか |
| 第三者からの閲覧 | 外部のAIサービスに送る場合、その会社が写真を学習や保存に使わない契約になっているか。社内の誰が見られるか |
| 同意 | 保護者の同意をどう取るか。子ども本人にも分かる説明にできるか |
| 品質 | 3方向で形がそろうか。実際に美容室で頼める形になるか（今の見本イラストと同じ基準で確かめる） |
| 費用 | 1回あたりの生成費用と、無料で提供できる回数。課金にする場合、子ども向けとして適切か |
| 代わりの方法 | 写真を使わずに、髪質や顔の形を選択式で入れて、見本イラストを選ぶ形で足りないか |

## 海外の類似アプリで見えた注意点

[design-references.md](design-references.md) の調査では、髪型試着アプリの多くが次のような作りだった。
- 自撮り写真を前提にしている
- 週ごとの定期購読で、見る前に課金させる

どちらも、ヘアみっけでは避ける。

## 判断の前提

- 写真を使わなくても、カタログ・比較・相談メモだけで、美容師さんに伝える目的が果たせていることを先に確かめる。
- 写真を扱うなら、使わない選択肢を常に残し、写真なしでもすべての機能が使えるようにする。
