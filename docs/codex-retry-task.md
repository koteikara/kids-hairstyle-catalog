# Codex作業指示：スポーツ刈り・ベリーショートの作り直し（1回だけ）

[codex-image-task.md](codex-image-task.md) の続き。2髪型は、ナチュラルショートやツーブロックと見分けがつかず不合格になった（[image-review.md](image-review.md) の2回目）。今回は、**その髪型だけの特徴を指示文の先頭に置いて**、1回ずつだけ生成する。

画風、保存場所、分割の手順は [codex-image-task.md](codex-image-task.md) と同じ。

## 1. 生成する

下の指示文を**そのまま**使い、各1回だけ生成する。作り直しはしない。

### `sports`（さっぱりスポーツ刈り）

```text
【この髪型の見分けどころ】横から見たとき、耳の下半分から襟足までがバリカンで短く刈り上げてあり、耳の上から上は短い普通の髪であること。刈り上げの上端は耳の真ん中の高さで、上の髪は刈り上げにかぶさらず、刈り上げと上の髪がなめらかにつながる（段差を作らない）。トップは3〜4cmで、頭の形に沿って丸く、ツーブロックよりも全体に短い。前髪はまゆの2〜3cm上で、おでこがはっきり見える短さ。
10歳くらいの日本の男の子の髪型見本を作成する。目的は美容室で髪型を選び、美容師に希望を伝えること。線画を主体とした、落ち着いたマンガ風のイラスト。写真風ではなく、髪型の輪郭、毛束、前髪、トップ、耳まわり、後頭部、襟足が読み取れる描写にする。髪型を主役にし、顔は控えめにする（目は小さめで、瞳の光は控えめ）。
同じ子ども、同じ髪型を、正面・真横（左向き）・後ろの3方向から描き、左から正面・横・後ろの順に横一列に並べた1枚の横長の画像にする。3つの絵は同じ縮尺・同じ高さにそろえ、絵と絵のあいだは十分にあける（重ねない）。各方向で頭の大きさ、髪の長さ、毛流れ、分け目、刈り上げの範囲、襟足の形を一致させる。
耳まわり：出す（耳全体が見える）。襟足：すっきりさせる（首すじが見える）。
子ども向けの注意：ノーセットの自然な状態で描く。ツンツンの立ち上げ、ワックスの艶、カラーは描かない。刈り上げは地肌が白く見えない長さにする。
描く範囲は頭から首まで（肩の線まで）。服は描かない。髪色は黒または暗い茶色で、黒の線と控えめなハッチングで表す。背景は白の無地。背景の模様、小物、文字、ラベル、ロゴは入れない。頭頂部のはねた毛（アホ毛）や飾りの毛は入れない。現実の小学生が美容室で注文できる髪型として描き、極端なデフォルメや非現実的な髪の形は避ける。カラー、パーマ、剃り込み、ラインは加えない。
```

### `veryshort`（ベリーショート）

## 2. 保存と分割

- 前回の画像は上書きせず、`img/styles/drafts/` に移してから生成する（例：`img/styles/drafts/sports-sheet-r2.png`）。
- 生成した画像を `img/styles/<ID>-sheet.png` に保存し、`scripts/split-sheet.ps1` で3枚に分ける。

## 3. 確認

[codex-image-task.md](codex-image-task.md) の4章に加えて、**ほかの髪型と並べて**確かめる。`node serve.js` のあと http://localhost:5173/tools/review.html を開き、正面・横・後ろを切り替えて見る。

- `sports`：横から見て、刈り上げの上端が耳の真ん中あたりにあり、ツーブロック（`twoblock`）と刈り上げの高さの違いが分かるか
- `veryshort`：正面から見て、前髪の下端が一直線にそろっていて、ナチュラルショート（`natural`）と見分けられるか

## 4. やらないこと

- `js/data.js` には登録しない（レビューのあとで登録する）。
- 作り直しは1回だけ。うまくいかなくても、それ以上は生成しない。

## 5. 報告

2髪型それぞれについて、3章の見分けどころを満たしたと思うかと、その理由を短く書く。
