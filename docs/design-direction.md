# デザインの方向性：バーバー・モノクロ（案）

- 作成：2026-09-27
- デザイン案： `node serve.js` のあと http://localhost:5173/design/mock.html （主要6画面の静止画。`design/`）
- 背景：今の「優しげな」印象から大きく変える。海外参考の方針は [design-references.md](design-references.md)。

## 考え方

- 理容室の看板やスタイルガイドのような、白と黒の強い対比にする。
- 主役は白黒の線画イラスト。色と飾りは、イラストより目立たせない。
- 10歳の男の子が「子どもっぽい」と感じない、道具らしい見た目にする。やわらかい角丸、パステル、キャラクターは使わない。
- 子ども向けの言葉（大きく、短く）と、親向けの事実（小さく、落ち着いて）を分ける。

## 色

| 名前 | 値 | 使う場所 |
|---|---|---|
| 墨 | `#111111` | 文字、罫線、上部のバー、選んだ状態 |
| 紙 | `#ffffff` | 背景 |
| 台 | `#f3f3f1` | イラストの下地 |
| 薄墨 | `#6b6b6b` | 補足の文字 |
| 罫 | `#d9d9d6` | 表の細い区切り |
| 赤 | `#e0301e` | **差し色はこれ1つ**。いちばん大事な行動（相談メモを作る・相談する・決定）、「相談したい」項目、提案 |
| 青 | `#1f3fbf` | サインポールの帯の飾りだけ |

## 文字

- 日本語：Zen Kaku Gothic New（900＝見出し、700＝ラベル、500＝本文）
- 英字：Oswald（見出しの添え、番号、手順の数。例：`No.04`、`STEP 3 / 6`、`TWO BLOCK`）
- 大きさは4段階に絞る：画面の見出し 26〜34px／項目の値 17〜22px／本文 13〜15px／ラベル 11〜12px

## 部品

- 角は四角（角丸にしない）。罫線は2px（大事な枠は3px）。
- タイル：2列の同じ大きさ。罫線で区切り、髪型番号・名前・特徴タグを1つ。
- チップ：四角い枠。選んだものは黒地に白。選んだ条件は、一覧の上に「×」付きで残す。
- 選択肢：左にイラスト、右に名前と一言、右端に丸。標準の値には `STANDARD` の印。最後に点線の枠で「わからない・美容師さんと相談」。
- 相談メモ：搭乗券のように、いちばん大事な項目（髪型名と刈り上げ）を大きく、部位ごとの項目を2列の枠で並べる。「相談したい」項目は赤地。
- 相談モード：上に赤い帯「美容師さんと相談中」。比較画像に「希望」（黒）と「提案」（赤）の印。項目ごとに OK／CHANGED／相談中。
- 刈り上げなどの段階は、四角のメーター（■■□）で示す。
- 上部に、サインポールの斜めの帯（赤・白・青）を細く入れる（ホームのみ）。
