# Codex作業指示：刈り上げ比較画像の生成と登録

「ヘアみっけ」のカード作成画面では、刈り上げを「なし・低め・中くらい・高め」の4段階から選ぶ。いまは仮の簡易図で比べているので、これを見本イラストと同じ画風の比較画像に置きかえる。

「刈り上げ」は言葉だけだとイメージが分かれやすい。**同じ子・同じ角度・同じ髪で、刈り上げの範囲だけが違う**4枚を並べ、親子が見比べて選べるようにするのが目的。

## 1. 最初に読むもの

| ファイル | 内容 |
|---|---|
| [illustration-guide.md](illustration-guide.md) | 画風、描写ルール、避ける表現。**必ず守る** |
| `img/styles/natural-sheet.webp` | 画風と顔立ちの基準 |
| `img/styles/twoblock-sheet.png` | 刈り上げの描き方（短い毛の質感、下へ薄くなじむ表現）の基準 |

Web上の写真や `docs/references.csv` のURL先の画像は、生成ツールへ入力・参照させない。

## 2. 作るもの

2枚の横長画像を作る。どちらも、**同じ子どもの同じ向きの頭を4つ、左から「なし・低め・中くらい・高め」の順に横一列**に並べる。

| 画像 | 向き | 保存先 |
|---|---|---|
| 後ろの比較 | 真後ろ | `img/fade/back-sheet.png` |
| 横の比較 | 真横（左向き） | `img/fade/side-sheet.png` |

### 4段階の定義（耳を目印にする）

アプリの説明文と同じ定義。高さは必ず耳を目印にして描く。

| 段階 | 番号 | 刈り上げの範囲 | 横から見たとき |
|---|---|---|---|
| なし | 0 | 刈り上げなし。耳まわりと襟足はハサミで短く整えた普通の髪 | 短い部分がどこにもない |
| 低め | 1 | 襟足の生えぎわから2〜3cm上まで | 刈り上げは首の後ろだけ。耳のまわり・耳より上は普通の髪 |
| 中くらい | 2 | 耳の真ん中の高さまで | 刈り上げの上端が耳の真ん中あたり |
| 高め | 3 | 耳の上端〜こめかみの高さまで | 刈り上げの上端が耳より上。上の髪が刈り上げに少しかぶる |

### 4つでそろえること

- 子ども、顔立ち、頭の大きさと位置、向き、線の太さ
- **上の髪**（トップ・前髪・後頭部の長さ、毛流れ、ボリューム）。4つとも同じにし、**刈り上げの範囲だけを変える**
- 刈り上げ部分の質感（短い毛、下へ薄くなじむ）。地肌が白く見えるほど短くしない
- 後ろの比較と横の比較で、同じ番号なら同じ高さ

## 3. 指示文

下の指示文をそのまま使う。

### 後ろの比較（`img/fade/back-sheet.png`）

```text

同じ子ども、同じ髪型の真後ろ姿を4つ、左から順に横一列に並べた1枚の横長の画像にする。4つは同じ縮尺・同じ高さ・同じ向きにそろえ、絵と絵のあいだは十分にあける（重ねない）。
4つとも、上の髪（トップ・後頭部の長さ、毛流れ、ボリューム）は完全に同じにし、刈り上げの範囲だけを変える。上の髪はナチュラルなショートヘア（トップ5cm前後、丸いシルエット）。耳は4つとも見えるようにする。
左から1つ目：刈り上げなし。耳まわりと襟足はハサミで短く整えた普通の髪。
2つ目：低め。襟足の生えぎわから2〜3cm上までだけをバリカンで短くし、上の髪となじませる。耳のまわりは普通の髪。
3つ目：中くらい。耳の真ん中の高さまでバリカンで短くし、上の髪となじませる。
4つ目：高め。耳の上端の高さまでバリカンで短くし、上の髪が刈り上げに少しかぶる。

```

## 4. 手順

1. `img/fade/` フォルダを作る。
2. 後ろの比較を生成し、`img/fade/back-sheet.png` に保存して4枚に分ける。

   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts/split-sheet.ps1 -src img/fade/back-sheet.png -outDir img/fade -prefix back -names "0,1,2,3"
   ```

   `back-0.png`〜`back-3.png` ができる。`could not split into 4 drawings` と出たら、4つの絵が近すぎるか重なっている。間を広くあけるよう指示して生成し直す。
3. 横の比較も同じようにする（`-src img/fade/side-sheet.png -prefix side`）。
4. 5章のチェックをすべて確かめる。満たさなければ、違う点を指示文に書き足して生成し直す（1枚につき最大3回）。
5. 合格したら、`js/data.js` の `window.HM_FADE_IMAGES` を次のように書きかえる。

   ```js
   window.HM_FADE_IMAGES = {
     side: ['img/fade/side-0.png', 'img/fade/side-1.png', 'img/fade/side-2.png', 'img/fade/side-3.png'],
     back: ['img/fade/back-0.png', 'img/fade/back-1.png', 'img/fade/back-2.png', 'img/fade/back-3.png']
   };
   ```

   片方だけ合格した場合は、合格した方だけを登録し、もう片方は `null` のままにする。
6. `node serve.js` でアプリを起動し、http://localhost:5173/#/make/twoblock の「刈り上げ」で、4段階が画像で並ぶことを確かめる（横の比較を登録した場合は2段目に並ぶ）。

## 5. チェック項目

- [ ] 4つの上の髪（トップ・前髪・後頭部）が同じに見える。違うのは刈り上げの範囲だけ
- [ ] 刈り上げが左から右へ、なし → 低め → 中くらい → 高めの順に、はっきり高くなっている
- [ ] 耳を目印にした高さが、2章の表どおり（低め＝首の後ろだけ、中くらい＝耳の真ん中、高め＝耳の上端〜こめかみ）
- [ ] 「なし」に短い部分が描き足されていない
- [ ] 後ろと横で、同じ番号の高さがそろっている
- [ ] 地肌が白く見えるほど短くない
- [ ] 文字、番号、ラベル、矢印、服、背景がない
- [ ] 画風が `natural-sheet.webp`、刈り上げの質感が `twoblock-sheet.png` とそろっている
- [ ] カード作成画面の小さい表示でも、4つの違いが一目で分かる

## 6. 変えてはいけないもの

- `js/data.js` は `window.HM_FADE_IMAGES` の書きかえだけにする。
- 髪型ごとの見本画像（`img/styles/`）は触らない。
