# Codex作業指示：耳まわりの比較画像の生成と登録

「ヘアみっけ」の髪型の詳細画面の「違いを比べる」に、耳まわりの比較を足す。親子が「耳まわりを短くして耳を出す場合と、髪を残して耳にかける・かくす場合で、どう見え方が変わるか」を、美容師さんと一緒に見比べられるようにするのが目的。

アプリ側は対応済み。画像を登録すれば、次の3か所に自動で表示される。
- 詳細画面の「耳まわり」タブ（今は「準備中」）
- 希望を選ぶ画面の「耳まわりは？」の選択肢
- 相談モードの耳まわりの項目

**同じ子・同じ角度・同じ髪で、耳まわりの髪の長さだけが違う**3枚を並べる。

## 1. 最初に読むもの

| ファイル | 内容 |
|---|---|
| [illustration-guide.md](illustration-guide.md) | 画風、描写ルール、避ける表現。**必ず守る** |
| `img/styles/natural-sheet.webp` | 画風と顔立ちの基準 |
| `img/compare/bangs-front-sheet.png`・`bangs-side-sheet.png` | 同じ頭で1か所だけ変える比較画像の見本（前髪の比較） |

Web上の写真や `docs/references.csv` のURL先の画像は、生成ツールへ入力・参照させない。

## 2. 作るもの

2枚の横長画像を作る。どちらも、**同じ子どもの同じ向きの頭を3つ、左から「出す・半分かかる・かくす」の順に横一列**に並べる。

| 画像 | 向き | 保存先 |
|---|---|---|
| 正面の比較 | 正面 | `img/compare/ears-front-sheet.png` |
| 横の比較 | 真横（左向き） | `img/compare/ears-side-sheet.png` |

### 3つの耳まわりの定義

| 順 | 値 | 耳まわりの髪 | 見え方 |
|---|---|---|---|
| 1 | `out` 出す | 耳のまわりを短く整え、耳に髪がかからない | 耳全体が見える |
| 2 | `half` 半分かかる | 耳の上に髪を残し、耳の上半分に髪がかぶる | 耳の下半分（耳たぶのあたり）だけが見える |
| 3 | `cover` かくす | 耳の下まで髪を残し、耳をおおう | 耳はほとんど見えない（耳たぶの先が少しのぞく程度） |

### 3つでそろえること

- 子ども、顔立ち、頭の大きさと位置、向き、線の太さ
- **耳まわり以外の髪**（トップの長さとボリューム、前髪、後頭部）。3つとも同じにし、**耳まわり（サイド）の髪の長さだけを変える**
- ベースの髪型はナチュラルショート（トップ5cm前後、前髪はまゆ毛くらいで自然に下ろす、刈り上げなし）
- 襟足は3つとも「自然に残す」長さにそろえる（「かくす」だけ襟足を長くしない）
- 刈り上げは3つとも入れない
- 正面の比較と横の比較で、同じ番号なら同じ耳まわり

## 3. 指示文

下の指示文をそのまま使う。

### 正面の比較（`img/compare/ears-front-sheet.png`）

```text
10歳くらいの日本の男の子の髪型見本。美容室で「耳まわり」の長さを選ぶための比較図。線画を主体とした、落ち着いたマンガ風のイラスト。顔は控えめにする（目は小さめで、瞳の光は控えめ）。
同じ子ども、同じ髪型の正面の顔を3つ、左から順に横一列に並べた1枚の横長の画像にする。3つは同じ縮尺・同じ高さ・同じ向きにそろえ、絵と絵のあいだは十分にあける（重ねない）。
3つとも、耳まわり以外の髪（トップの長さとボリューム、前髪）は完全に同じにし、耳まわり（サイド）の髪の長さだけを変える。髪型はナチュラルなショートヘア（トップ5cm前後、丸いシルエット、前髪はまゆ毛くらいで自然に下ろす、刈り上げなし）。耳は左右とも描き、髪と耳の重なりがはっきり分かるようにする。
左から1つ目：耳を出す。耳のまわりを短く整え、耳に髪がかからない。耳全体が見える。
2つ目：耳に半分かかる。耳の上に髪を残し、耳の上半分に髪がかぶる。耳の下半分だけが見える。

```

## 4. 手順

1. 正面の比較を生成し、`img/compare/ears-front-sheet.png` に保存して3枚に分ける。

   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts/split-sheet.ps1 -src img/compare/ears-front-sheet.png -outDir img/compare -prefix ears-front -names "out,half,cover"
   ```

   `ears-front-out.png`・`ears-front-half.png`・`ears-front-cover.png` ができる。`could not split into 3 drawings` と出たら、3つの絵が近すぎるか重なっている。間を広くあけるよう指示して生成し直す。
2. 横の比較も同じようにする（`-src img/compare/ears-side-sheet.png -prefix ears-side`）。
3. 5章のチェックをすべて確かめる。満たさなければ、違う点を指示文に書き足して生成し直す（1枚につき最大3回）。不採用版は `img/compare/drafts/` に移す。
4. 合格したら、`js/data.js` の `window.HM_COMPARE_IMAGES` に `ear` を足す（`fade`・`bangShape` はそのまま残す）。

   ```js
   ear: {
     front: { out: 'img/compare/ears-front-out.png', half: 'img/compare/ears-front-half.png', cover: 'img/compare/ears-front-cover.png' },
     side: { out: 'img/compare/ears-side-out.png', half: 'img/compare/ears-side-half.png', cover: 'img/compare/ears-side-cover.png' }
   }
   ```

   片方だけ合格した場合は、合格した向きだけを登録する。
5. `node serve.js` でアプリを起動して、次を確かめる。
   - http://localhost:5173/#/style/mash の「違いを比べる」で「耳まわり」タブが押せ、3つが並ぶ（正面から・横から を切りかえられる）。マッシュは「耳に半分かかる」が見本として印が付く
   - http://localhost:5173/#/make/natural の「耳まわりは？」で、3つの選択肢すべてに画像が付く

## 5. チェック項目

- [ ] 3つの耳まわり以外の髪（トップ・前髪・後頭部・襟足）が同じに見える。違うのは耳まわりの髪の長さだけ
- [ ] 2章の表どおりになっている（出す＝耳全体が見える／半分＝耳の上半分に髪がかぶる／かくす＝耳がほとんど見えない）
- [ ] 耳の見え方が、左から右へ「全体が見える → ほとんど見えない」の順になっている
- [ ] 「かくす」の襟足が、ほかの2つより長くなっていない
- [ ] 刈り上げが描かれていない
- [ ] 正面と横で、同じ番号の耳まわりがそろっている
- [ ] 背景が白の無地で、透明になっていない
- [ ] 文字、番号、ラベル、矢印、服がない
- [ ] 画風が `natural-sheet.webp`、比較の作り方が前髪の比較とそろっている
- [ ] 詳細画面の小さい表示（3つ横並び）でも、3つの違いが一目で分かる

## 6. 変えてはいけないもの

- `js/data.js` は `window.HM_COMPARE_IMAGES` への `ear` の追加だけにする。
- 髪型ごとの見本画像（`img/styles/`）、刈り上げ（`img/fade/`）と前髪（`img/compare/bangs-*`）の比較画像は触らない。
- `js/app.js` などのコードは変えない（アプリ側は対応済み）。
- git のコミットやpushはしない（レビューのあとで反映する）。
