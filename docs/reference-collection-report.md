## 分かったこと（1回目）

### 使えない出典

- **ホットペッパービューティー、minimo、サンキュ！（ベネッセ）は、利用規約上NG**と判断した。例として、ホットペッパービューティー利用規約の第5条は、引用の範囲を超えて画像や掲載情報を承諾なく使うことを禁じている。キッズのスタイル写真が最も多いサイトだが、今後の収集対象から外す。
- 2回目では、IG BEAUTY BOOK（IMAGE-A）も規約で無断転用・複製を禁じていたため除外した。
- 美容師のコラム記事は、ストックフォトや大人の写真が多く、小学生の実例として使えないことが多い。

### 使えそうな出典と注意点

- **子ども専門サロンのヘアカタログ（チョッキンズ、GooCHOKI）** が主な出典になった。正面・横・後ろの写真がそろっていることが多く、特徴を確かめやすい。
- ただし、写っているのは **4〜6歳の未就学児〜小学1年生が中心** で、10歳前後の実例はほとんどない。高学年向けの髪型（アップバング、ソフトモヒカン、ツーブロック）で参考が残らなかった主な理由でもある。
- 残った9件はすべて、利用規約が「未確定」（規約ページがない、または禁止の明文が見つからない）。「使ってよい」と確かめられたわけではない。写真の転用はせず、特徴メモとして使うだけにとどめる。法務の確認は、個人プロジェクトのため行わない（2026-09-27決定）。

### 特徴の根拠

- 残った9件のうち8件は、検証エージェントがブラウザで写真を実際に見て特徴を確かめた。ベリーショートの1件（チョッキンズ 4544）は、ページの文章だけによる。

### 髪型どうしの見分け方（イラストで描き分ける点）

- 丸みショートとショートボブ：後ろの裾。丸みショートは襟足が短く首が見え、後頭部の高い位置が丸い。ショートボブは裾があごの高さまで下りる。
- ショートボブとぱっつんボブ：ぱっつんボブは前髪も裾も一直線で、段がなく重い。ショートボブは前髪を自然に下ろし、毛先が内に丸まる。
- ぱっつんボブと切りっぱなしボブ：長さ（あご／肩上）と毛先（内に入る／まっすぐか外に軽くはねる）。
- 3つのロング：前髪（一直線／なし）と、顔まわりの段（なし／あご下から段）。
