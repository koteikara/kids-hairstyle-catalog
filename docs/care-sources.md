# 再現しやすさ・手入れの目安：資料の一覧（2026-10-07）

髪型データ `window.HM_CARE`（js/data.js）の根拠。収集と検証を別々のエージェントで行い（4グループ×2）、検証で指摘された言いすぎ・資料にない断定・大人向けの話の当てはめは直してから載せた。

- **監修なし。** 画面では「目安」と書き、最後は美容師さんと相談するよう促す（[spec.md](spec.md) 8章の決定5）。
- **大人向けの資料が多い。** 子どもに当てはまる部分だけを使った。パーマ、縮毛矯正、ヘアアイロン、ワックス前提の対策は子ども向けに取り入れていない。
- **カットの間隔は「形をきれいに保つなら」の目安。** 子どもは実際には2〜6か月ごとのことも多い（Monan のコラム）。
- **資料にない項目は一般論。** 朝のセットの時間や「自分でできるか」は、多くが一般論。
- **外した資料：** All About（無断転載を禁止）、学研 子育てまっぷ（サイトポリシーで複製・転載を禁止）、デミ コスメティクス（規約で無断転載・複製を禁止）。ホットペッパービューティー、minimo などは最初から除外。
- 文章は写さず、事実だけを短くまとめた。
