# Codex作業指示：前髪の比較画像の生成と登録

「ヘアみっけ」の髪型の詳細画面の「違いを比べる」に、前髪の比較を足す。親子が「前髪を下ろす場合と上げる場合で、どう見え方が変わるか」を、美容師さんと一緒に見比べられるようにするのが目的。

アプリ側は対応済み。画像を登録すれば、次の3か所に自動で表示される。
- 詳細画面の「前髪」タブ（今は「準備中」）
- 希望を選ぶ画面の「前髪はどうする？」の選択肢
- 相談モードの前髪の項目

**同じ子・同じ角度・同じ髪で、前髪の形だけが違う**4枚を並べる。

## 1. 最初に読むもの

| ファイル | 内容 |
|---|---|
| [illustration-guide.md](illustration-guide.md) | 画風、描写ルール、避ける表現。**必ず守る** |
| `img/styles/natural-sheet.webp` | 画風と顔立ちの基準 |
| `img/fade/back-sheet.png`・`side-sheet.png` | 同じ頭で1か所だけ変える比較画像の見本（刈り上げの比較） |

Web上の写真や `docs/references.csv` のURL先の画像は、生成ツールへ入力・参照させない。

## 2. 作るもの

2枚の横長画像を作る。どちらも、**同じ子どもの同じ向きの頭を4つ、左から「自然に下ろす・横に流す・まん中で分ける・上げる」の順に横一列**に並べる。

| 画像 | 向き | 保存先 |
|---|---|---|
| 正面の比較 | 正面 | `img/compare/bangs-front-sheet.png` |
| 横の比較 | 真横（左向き） | `img/compare/bangs-side-sheet.png` |

### 4つの前髪の定義

| 順 | 値 | 前髪の形 | 見え方 |
|---|---|---|---|
| 1 | `natural` 自然に下ろす | 前髪を下ろし、毛先はまゆ毛くらい。分け目なし | おでこはほとんど見えない |
| 2 | `side` 横に流す | 片側（向かって左）の分け目から、反対側へ斜めに流す。毛先はまゆ毛くらい | おでこが斜めに少し見える |
| 3 | `center` まん中で分ける | まん中の分け目から左右へ、カーテンのように流す | おでこのまん中が細く見える |
| 4 | `up` 上げる | 前髪を根元からふんわり上げて、後ろへ流す。分け目は作らない | おでこ全体が見える。立ち上がりは2〜3cm程度 |

### 4つでそろえること

- 子ども、顔立ち、頭の大きさと位置、向き、線の太さ
- **前髪以外の髪**（トップの長さとボリューム、サイド、耳まわり、後頭部、襟足）。4つとも同じにし、**前髪の形だけを変える**
- ベースの髪型はナチュラルショート（トップ5cm前後、耳を出す、刈り上げなし、襟足は自然に残す）
- 前髪の長さは4つとも同じ（下ろしたときにまゆ毛くらいになる長さ）。形だけが違う
- 正面の比較と横の比較で、同じ番号なら同じ前髪

下の指示文をそのまま使う。

```text

同じ子ども、同じ髪型の正面の顔を4つ、左から順に横一列に並べた1枚の横長の画像にする。4つは同じ縮尺・同じ高さ・同じ向きにそろえ、絵と絵のあいだは十分にあける（重ねない）。
4つとも、前髪以外の髪（トップの長さとボリューム、サイド、耳まわり）は完全に同じにし、前髪の形だけを変える。髪型はナチュラルなショートヘア（トップ5cm前後、丸いシルエット、耳を出す、刈り上げなし）。前髪の長さは4つとも同じで、下ろすとまゆ毛くらいになる長さ。

2つ目：向かって左の分け目から、前髪を反対側へ斜めに流す。毛先はまゆ毛くらい。おでこが斜めに少し見える。
3つ目：まん中で分けて、前髪を左右へカーテンのように流す。おでこのまん中が細く見える。
```

## 4. 手順

1. `img/compare/` フォルダを作る。
2. 正面の比較を生成し、`img/compare/bangs-front-sheet.png` に保存して4枚に分ける。

   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts/split-sheet.ps1 -src img/compare/bangs-front-sheet.png -outDir img/compare -prefix bangs-front -names "natural,side,center,up"
   ```

   `bangs-front-natural.png`・`bangs-front-side.png`・`bangs-front-center.png`・`bangs-front-up.png` ができる。`could not split into 4 drawings` と出たら、4つの絵が近すぎるか重なっている。間を広くあけるよう指示して生成し直す。
3. 横の比較も同じようにする（`-src img/compare/bangs-side-sheet.png -prefix bangs-side`）。
4. 5章のチェックをすべて確かめる。満たさなければ、違う点を指示文に書き足して生成し直す（1枚につき最大3回）。
5. 合格したら、`js/data.js` の `window.HM_COMPARE_IMAGES` に `bangShape` を足す。

   ```js
   window.HM_COMPARE_IMAGES = {
     fade: window.HM_FADE_IMAGES,
     bangShape: {
       front: { natural: 'img/compare/bangs-front-natural.png', side: 'img/compare/bangs-front-side.png', center: 'img/compare/bangs-front-center.png', up: 'img/compare/bangs-front-up.png' },
       side: { natural: 'img/compare/bangs-side-natural.png', side: 'img/compare/bangs-side-side.png', center: 'img/compare/bangs-side-center.png', up: 'img/compare/bangs-side-up.png' }
     }
   };
   ```

   片方だけ合格した場合は、合格した向きだけを登録する（例：`bangShape: { front: { ... } }`）。
6. `node serve.js` でアプリを起動して、次を確かめる。
   - http://localhost:5173/#/style/natural の「違いを比べる」で「前髪」タブが押せ、4つが並ぶ（正面から・横から を切りかえられる）
   - http://localhost:5173/#/make/sidepart の「前髪はどうする？」で「横に流す」に画像が付く

## 5. チェック項目

- [ ] 4つの前髪以外の髪（トップ・サイド・耳まわり・後頭部・襟足）が同じに見える。違うのは前髪の形だけ
- [ ] 4つの前髪の長さがそろっている（下ろしたときにまゆ毛くらい）
- [ ] 2章の表どおりの形になっている（下ろす／斜めに流す／まん中分け／上げる）。とくに「上げる」は分け目のない立ち上がりで、七三や横流しになっていない
- [ ] おでこの見え方が、左から右へ「ほとんど見えない → 全体が見える」の順になっている
- [ ] 正面と横で、同じ番号の前髪がそろっている
- [ ] 「上げる」がツンツンに尖っていない。整髪料の強いツヤがない
- [ ] 文字、番号、ラベル、矢印、服、背景がない
- [ ] 画風が `natural-sheet.webp` とそろっている
- [ ] 詳細画面の小さい表示（4つ横並び）でも、4つの違いが一目で分かる

## 6. 変えてはいけないもの

- `js/data.js` は `window.HM_COMPARE_IMAGES` への `bangShape` の追加だけにする。
- 髪型ごとの見本画像（`img/styles/`）と、刈り上げの比較画像（`img/fade/`）は触らない。
- `js/app.js` などのコードは変えない（アプリ側は対応済み）。
